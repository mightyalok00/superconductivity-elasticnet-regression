# Architecture

## Application Flow

~~~mermaid
flowchart LR
    A[User / API Client] --> B[FastAPI]
    B --> C[Input Validation]
    C --> D[Out-of-Distribution Check]
    D --> E[StandardScaler]
    E --> F[ElasticNet v1]
    F --> G[Critical Temperature Prediction]
    G --> H[JSON or CSV Response]
~~~

## Deployment Flow

~~~mermaid
flowchart LR
    A[GitHub Repository] --> B[GitHub Actions]
    B --> C[Model Artifact + Tests]
    C --> D[Railway]
    D --> E[Uvicorn + FastAPI]
    E --> F[Public HTTPS API]
~~~

## Artifact Flow

The deployment model is generated by:

~~~bash
python scripts/train_deployment_model.py
~~~

This produces:

- `outputs/models/elasticnet_v1.joblib`
- `outputs/models/model_metadata.json`

The API loads the artifact when available and falls back to on-demand training only if the artifact is missing.
